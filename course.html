COURSES

My teaching and training activities focus on electromagnetic compliance, computational electromagnetics, parallel programming, and high performance computing for scientific and engineering applications.

Courses Taught

  • Large Language Models: A Hands-on Approach
    CCE Proficiency Course, IISc Bangalore, Jan-May 2026.
    Summary: Engineering-focused course on large language models covering transformer architectures, GPU-aware inference, fine-tuning, quantization, KV caching, LLM serving, retrieval-augmented generation, agentic systems, multimodal models, evaluation, and hands-on labs/projects for scalable LLM deployment.
  • Fundamentals of Electromagnetic Compliance for Electrical System Design
    CCE Proficiency Course, IISc Bangalore, Aug-Dec 2024.
    Summary: Introduces electromagnetic compatibility and interference issues in electrical system design, including coupling mechanisms, grounding, shielding, filtering, layout practices, and compliance-oriented design considerations.
  • Parallel Programming and Introduction to High Performance Computing
    CCE Proficiency Course, IISc Bangalore, Aug-Dec 2023 and Jan-Apr 2025.
    Summary: Covers fundamentals of high performance computing, shared-memory and distributed-memory programming, parallel algorithms, performance measurement, scalability, and hands-on scientific computing examples.
  • Parallel Programming Hands-on
    National Supercomputer Mission (NSM) Faculty Development Program on Parallel Programming for HPC Systems, SERC, IISc Bangalore, 11-16 Sep. 2017.
    Summary: Hands-on faculty development training focused on practical parallel programming methods for HPC systems, including parallel code development, execution workflows, and performance analysis.
  • Parallel Programming Hands-on
    SERC HPC Training Course, IISc Bangalore, 15-16 Feb. 2019.
    Summary: Practical HPC training course covering basic parallel programming concepts, job execution on shared computing systems, and performance-aware implementation of scientific applications.
